# 管理端业务化精简实施记录

## 背景与目标

当前版本面向业务试用，原“高级设置”同时暴露企业身份治理、工具注册、审计、运行治理和 FinOps，入口密度过高且会让业务管理员误以为必须先理解技术治理能力。此次调整以“不影响知识库和智能体使用”为硬边界，将非业务治理能力从当前管理端界面和前端构建入口移除，但不删除后端 API、数据库结构、审计记录或运行策略。

## 当前版本的信息架构

管理后台一级入口从 6 个收敛为 5 个：

1. 业务概览
2. 组织与成员
3. 智能体中心
4. 知识中心
5. 业务管理

“高级设置”一级入口已移除。

### 智能体中心

保留以下二级入口：

- 智能体
- 角色蓝图
- 测试与发布
- 模型服务

模型服务从高级设置迁入智能体中心，因为模型选择和路由是智能体能够真实回复的必要配置。智能体页面不再加载或展示租户 Token、成本、并发、速率和月度配额表单。

### 知识中心

知识库、文档上传、解析、检索、发布、经验候选等入口和接口保持不变。此次改动没有修改知识入库、知识权限、向量检索、知识绑定或智能体引用知识的调用链。

### 个人账号安全

个人“账号与安全”和“修改密码”继续保留在头像菜单，不占一级导航。移除的是截图中的企业级 SSO、SCIM 与企业身份策略管理页面，不是个人账号恢复能力。

## 从当前版本界面移除的模块

- 企业身份与安全治理：SSO、SCIM、企业策略。
- 工具与连接器注册、测试和发布。
- 审计查询、链校验和导出页面。
- 流程、事件、异常投递和 DLQ 运行治理页面。
- FinOps、成本、预算、Token 和租户配额页面。

对应后端模块、契约、权限校验、数据库表和测试仍保留，后续版本可以重新接入。当前 `AdminShell` 不再导入这些页面，因此它们不会进入本版管理端主构建包。

## 兼容策略

- 旧 `#advanced-settings` 链接跳转到智能体中心的模型服务。
- 旧企业身份、工具、审计、运行治理和 FinOps 链接跳转到业务概览。
- 非管理员直接访问旧治理链接仍按原权限规则拒绝，并回到其允许访问的知识中心。
- 后端 API 未删除，避免破坏后台任务、知识链路、智能体运行和历史数据。

## 业务概览调整

管理概览移除了 FinOps、Token、成本微单位、Outbox 队列和治理告警卡片，保留：

- 启用成员与近期活跃。
- 真实可用智能体和智能体使用效果。
- 知识文档、解析和向量覆盖状态。
- 飞书/组织通讯录同步状态。

## 已验证结果

- TypeScript 类型检查：5/5 包通过。
- JavaScript/TypeScript 测试：338 个测试文件、1843 项通过。
  - Contracts：209 项。
  - API：1258 项；155 项数据库集成测试按环境配置跳过。
  - Admin：58 个文件、202 项。
  - Desktop：41 个文件、174 项。
- 生产构建：Contracts、API、Admin、Desktop 全部通过。
- 管理端生产包从 228 个模块降至 212 个模块。
- 管理端 JS 从约 1087.85 kB 降至 971.94 kB，CSS 从约 135.38 kB 降至 114.17 kB。
- 本地 API、AI Runtime 和管理后台仍保持 HTTP 200；Electron 桌面端不依赖被移除的管理页面。

## 风险与边界

- 当前只是从本版 UI 和前端构建入口移除高级治理能力，并非废弃后端治理设计。
- 模型服务页面仍包含必要的供应商和路由配置，这是智能体可用性的前置条件，不能一并删除。
- 飞书凭据配置仍保留在“组织与成员”的同步流程内，因为通讯录同步属于业务接入能力。
- 管理端主包仍大于 500 kB，构建会给出拆包警告；本轮移除治理模块后体积已经下降，但后续仍建议按一级页面进行动态加载。

## 验收结论

当前版本已达到“只展示业务主流程”的交付目标：业务管理员不会再看到截图中的五类高级治理入口；知识库和智能体配置仍可访问，模型服务被保留在智能体上下文中，旧链接不会产生空白页面或暴露已移除页面。
