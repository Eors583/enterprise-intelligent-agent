# 用户端 AI 与知识库接入核查

核查时间：2026-08-10（Asia/Shanghai）

## 结论

用户端 AI 的知识库调用链已经在代码和测试层完成接入，但当前本地运行实例还不能认定为“用户可正常使用”。知识库、检索 Gateway、Agent Run Worker、引用回传和桌面端引用展示均已接通；真正阻塞用户对话的是模型运行门禁，而不是知识库。

当前模型路由状态为 `NOT_READY / INSUFFICIENT_EVIDENCE`，原因是 `NO_RECENT_SUCCESSFUL_PROVIDER_EVIDENCE`。Runtime 本地探针为 `READY`，但最近 24 小时真实 Provider 调用证据为 `0/1`。系统会在创建对话或执行 Agent Run 前失败关闭，返回或记录 `AGENT_OPERATIONAL_NOT_READY`，因此当前 8 个已启用智能体均未达到可运行门禁。

## 已确认的调用链

1. 桌面端消息调用 Conversation API，并选择员工智能体或部门智能体。
2. Conversation API 在创建或追加智能体会话前检查智能体运行门禁。
3. Agent Run Worker 准备执行快照，读取智能体当前绑定的 `knowledgeBaseIds`。
4. Agent Run 通过 `KnowledgeRetrievalGateway` 检索，不直接访问知识表、Qdrant collection 或对象存储目录。
5. 检索以提问用户身份执行租户、成员、组织、项目、任务、数据标签和知识访问过滤。
6. 检索结果作为知识来源送入模型；模型回复中的内部来源标记会被转换为用户可见的 `[来源N]`。
7. 持久化回答前再次校验切片访问权限，最终引用随消息保存。
8. 桌面端消息页展示“知识来源”卡片，并可打开有权访问的来源。

## 当前阻塞

模型服务当前只有“配置和本地 Runtime 就绪”的证据，没有最近 24 小时真实供应商调用成功证据。该证据门禁会实际阻止用户端 AI 运行，并非纯展示提示：

- Conversation API 会返回 HTTP 503，错误码为 `AGENT_OPERATIONAL_NOT_READY`。
- Agent Run Worker 会把运行标记为失败，错误码同为 `AGENT_OPERATIONAL_NOT_READY`。
- 受控“真实模型连通性测试”可以创建一次独立 Agent Run 验证 Provider；本次状态核查没有替用户执行该有外部调用和可能产生成本的操作。

### 可核验回答降级与最终复测

真实模型存在偶发未输出合法内部来源标记的情况。原有安全校验会正确丢弃无法核验的模型回答，但会统一提示“没有找到足够可靠的依据”，即使本次检索实际已取得请求员工有权访问的切片。这会影响用户对知识库可用性的判断。

现已在生产 Agent Run 准备快照中启用“授权证据回退”：仅当本次请求已经通过知识权限过滤并取得非空来源、但模型回答无法完成来源核验时，系统丢弃模型生成内容，改为最多展示 3 条本次授权检索返回的原文摘录及对应 `[来源N]`。无授权来源时仍返回无依据提示；回退不会使用未核验模型内容，也不会扩大知识库、文档或切片的可访问范围。

## 2026-08-10 后台知识库统一接入

本次进一步取消了员工智能体侧维护独立知识库清单的做法。个人智能体使用 `owner-authorized` 知识范围时，每次 Agent Run 都会通过 `KnowledgeGateway`，按当前提问员工身份动态解析后台管理端已经启用且有权访问的知识库；公司公开、部门范围和指定成员范围继续由知识边界统一判定。员工端不复制知识库、文档或向量数据，也不直接访问知识表、Qdrant collection 或对象存储目录。

为避免新上传资料继续停留在“后台看得见、员工智能体用不了”的草稿状态，管理端新建知识库的默认状态调整为 `ACTIVE`，并增加前向迁移，将已有且包含 `READY` 当前文档版本的草稿知识库激活。无可用文档的空知识库仍保持草稿，已归档知识库不会重新进入检索范围。

蓝血研究租户中的“Claude_Code_实战训练营”知识库已通过知识公共管理 API 完成索引修复：2/2 篇文档就绪、10/10 个切片已向量化，活动索引版本为 `local-fastembed:BAAI/bge-small-zh-v1.5:pad-1536-v1`、1536 维，语义覆盖率为 100%。以目标成员 `96a2feb7-c833-488b-836b-a7c1a6921c78` 模拟检索时，权限解析结果只包含后台知识库 `74550ec3-4f8e-46e0-a7d0-fae201015a07`；查询“Claude Code 是什么、训练营讲什么”返回 3 个对应课程大纲切片，关键词、向量、关系扩展、重排和查询路由诊断均为 `APPLIED`，检索模式为 `HYBRID`，无降级原因。
