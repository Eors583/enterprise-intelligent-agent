# 知识检索、智能体绑定与头脑风暴核心闭环

## 背景与目标

本轮按“先把员工能用的基础功能跑通”的范围实施，不扩展新的企业治理门禁。目标是让管理员上传到知识库的资料完成切片和向量化后，可以直接绑定到员工智能体或部门智能体；员工在统一消息窗口中提问时，智能体按当前用户权限检索知识，并在双智能体群聊中进行有限轮次的头脑风暴。

## 已实现能力

### 文档检索与召回

- 沿用 PostgreSQL、pgvector 和 AI Runtime 的本地 FastEmbed/BGE 能力，执行关键词与向量混合检索，并使用 Cross Encoder 重排。
- 知识库可配置混合、向量或全文检索；混合检索按语义/关键词权重融合，Cross Encoder 没有留下满足阈值的候选时回退到加权召回结果，避免把有效候选错误清空。
- Agent Run 的知识范围在创建时写入不可变策略快照；每次执行仍由 API 重新校验租户、成员、组织和知识权限。
- 模型输出只接受本次实际召回切片的来源标记。兼容模型把中文标点放在来源标记后的自然写法，同时继续拒绝伪造切片、无来源事实和越权来源。

### 员工智能体与部门智能体

- `AgentInstance` 支持 `MEMBER` 与 `DEPARTMENT` 两种实例类型；部门智能体关联一个组织部门。
- 管理后台可以创建部门智能体，并通过知识库多选直接配置该智能体可使用的知识库。
- 员工智能体和部门智能体均支持实例级知识库绑定覆盖，不需要为了调整知识库而生成一个未经测试的新提示词版本；实际运行仍把有效知识范围固化到 Run 快照。
- 员工启动数据只返回一个确定的当前员工智能体，避免历史重复实例造成随机选中未绑定知识库的旧实例。
- 部门智能体仅对当前在该部门有有效任职关系的员工可见和可执行。

### 统一聊天与双智能体头脑风暴

- 新建会话统一展示员工、员工智能体和当前部门智能体。
- 群聊允许只选择智能体，也允许同时选择员工；基础头脑风暴最多选择两个智能体。
- 选择两个智能体时，服务端创建 4 轮受控交替链路，两个智能体使用同一群会话上下文继续讨论，不进行无限递归或广播。
- 每一轮使用该轮智能体自己的知识库范围，并保留运行状态、消息和引用。

### 运行失败可理解性

- 修复 AI Runtime 将可选 `safety_decision` 序列化为 `null` 时被 API 错判为非法响应的问题。
- 供应商明确返回不可用时，Run 现在保持可判定失败语义，不再因为该空字段误报为 `UNKNOWN`。

## 当前边界与后续行动

- 当前开发库只有 2 个当前切片，证明了端到端链路，但不能代表大规模企业语料的召回质量。下一阶段应补充真实部门资料集和问题集，测量召回率、准确率与无答案率。
- 关系图谱检索当前显示 `KNOWLEDGE_RELATIONSHIP_GRAPH_UNAVAILABLE`，关键词、向量和重排链路可用；强关系检索仍需在真实关系数据发布后单独验收。
- Manus 属于外部供应商，验收期间出现过一次 `PROVIDER_UNAVAILABLE`，随后恢复并完成 4 轮讨论。产品已能明确反馈失败，但供应商稳定性不由本仓库保证。
- 当前部门可见性按员工的直接有效任职部门判断；如需要上级部门智能体覆盖全部子部门，应增加明确的“包含子部门”业务选项，而不是默认扩大权限。
- 双智能体头脑风暴当前是固定 4 轮基础模式，尚未增加目标模板、人工中途介入、结论整理和任务沉淀。这些应在基础使用反馈稳定后继续实现。

## 2026-08-04 初版门禁移除

为避免审核与评测流程妨碍“智能体 + 知识库”基础闭环验证，本轮将发布治理改为可选质量能力：

- 知识库可以在没有文档、向量或图谱时直接创建/切换为 `ACTIVE`；readiness 接口只返回检索诊断。
- 文档版本只要达到 `READY` 且存在切片即可发布，不再要求解析复核、治理审批、有效期策略或通过的 Evaluation Run。
- 图谱候选存在时随文档发布激活；候选不存在也不阻塞文档发布。带当前版本来源证据的活动关系可直接参与最多两跳扩展，本体与冲突状态保留为非阻塞诊断。
- 角色智能体版本可以从 `DRAFT` 或 `TESTING` 直接发布；已发布且结构化快照有效的版本可以用于任命，不再要求双人审核或 Evaluation Run。
- 管理后台删除启用、文档发布和角色版本发布按钮上的评测/审核禁用条件；质量评测入口仍保留，但明确为可选质量检查。

仍保留的基础约束包括：登录与租户隔离、知识库范围过滤、文件格式/大小/安全检查、文档必须解析分块成功、乐观锁与版本单调性、活动关系必须具有当前发布版本的来源证据，以及回答引用二次校验。这些属于数据正确性和检索真实性约束，不是本次移除的业务发布门禁。
