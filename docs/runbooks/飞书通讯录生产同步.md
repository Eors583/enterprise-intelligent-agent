# 飞书通讯录生产同步

飞书通讯录采用“生成差异预览 → 管理员确认 → Outbox 后台应用”的闭环。任何组织写入都必须引用未过期的持久化预览；后台 Worker 会重新拉取飞书快照并校验 SHA-256 cursor，快照变化时以 `SNAPSHOT_CHANGED` 失败关闭，不会套用旧预览。

## 运行配置

- `FEISHU_SYNC_WORKER_ENABLED=true`：启用持久化后台 Worker。Prisma 模式默认启用。
- `FEISHU_SYNC_PREVIEW_TTL_MS=900000`：预览有效期。
- `FEISHU_SYNC_WORKER_POLL_INTERVAL_MS=2000`：轮询周期。
- `FEISHU_SYNC_WORKER_BATCH_SIZE=2`：单次领取数量。
- `FEISHU_SYNC_MAX_ATTEMPTS=4`：最大执行次数，耗尽后进入死信。
- `FEISHU_SYNC_LEASE_MS=1800000`：Run、Integration 与 Outbox 锁租约；执行中按三分之一租约周期续租。
- `FEISHU_SYNC_RETRY_BASE_MS=10000`、`FEISHU_SYNC_RETRY_MAX_MS=300000`：指数退避范围。

生产环境应为 `OUTBOX_DATABASE_URL` 使用仅具备 `enterprise_agent_outbox` 能力的独立数据库登录。飞书 App Secret 仅以 AES-256-GCM 密文保存，接口、审计与错误信息均不回传密钥。密文使用租户 ID、连接器类型和 App ID 作为 AAD，不能跨租户或跨应用重放。

连接器凭据必须使用独立于认证令牌的版本化密钥环：

- `CONNECTOR_CREDENTIAL_KEYRING_JSON`：键 ID 到 32 字节 base64url 密钥的 JSON 映射；
- `CONNECTOR_CREDENTIAL_ACTIVE_KEY_ID`：新密文使用的写入密钥；
- 轮换时先加入新密钥并切换 active ID，确认旧密文完成重绑或重加密后才可移除旧密钥；
- 历史 `v1` 密文仅保留迁移期读取兼容，新写入一律使用带 key ID 与 AAD 的 `v2` 信封；
- 生产环境缺少专用密钥环时 API 必须拒绝启动，禁止复用 `AUTH_TOKEN_PEPPER`。

## 管理流程

1. 管理员绑定并验证企业自建应用。
2. `POST /admin/integrations/feishu/organization-sync/preview` 拉取快照并生成逐项差异。
3. 管理员检查新增、更新、归档、停用、冲突和逐项诊断。
4. `POST /admin/integrations/feishu/organization-sync/runs` 提交 `previewId` 与调用方幂等键。
5. Worker 领取 Run 与 Outbox 锁，重新取快照并核验 cursor。
6. 组织写入、Run 成功、预览应用状态、逐项状态及 Outbox 发布在同一租户事务中提交。
7. `GET .../runs` 查看最近 50 条历史；`GET .../preview` 查看最新预览及逐项结果。

## 故障和恢复

- Worker 进程崩溃：Run/Outbox 租约到期后由其他副本重新领取。
- 可重试供应商或数据库错误：指数退避，达到 `maxAttempts` 后进入 `DEAD_LETTER`。
- `PREVIEW_EXPIRED` / `SNAPSHOT_CHANGED`：不可重试，管理员必须重新生成预览。
- `PROTECTED_OWNER_OFFBOARDING`：不会自动停用租户所有者，管理员需先移交所有权。
- 成员停用或离职：撤销登录会话，递归回收有效 Role Assignment，取消关联 Agent Run，并写入外部取消 Outbox。

健康接口 `/health/ready` 的 `feishuDirectorySync` 字段会明确返回 `enabled` 或 `disabled`。恢复验收必须覆盖 `directory_sync_previews`、`directory_sync_preview_items`、`directory_sync_runs` 的 RLS、ACL、外键及索引。
